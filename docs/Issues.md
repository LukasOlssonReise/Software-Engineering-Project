## Task
A concrete piece of work needed to implement a feature or story.

Describe exactly what needs to be done.

Example:
Add form validation to the loan application form: make citizen number, name, and requested loan amount mandatory fields.

### Sprint 1
**Browse Page:** Add an browser page where items can be described with: name, description and photo.
**Item Listing Form:** Add an listing form where users can create a new item to lend, this will include: name, description and photo.
**Item Search Bar:** Add a simple search bar with text search for item name.
**Create an account:** Add a option to create an account, to create an account they need to provide with an name and a password.
### Sprint 2
**Category Filter:** Add a category filter in browser page where student can filter through items.
**Account Page:** Add an account page where users can look through their profile, this will include: name, email and password.
**Borrow Request:** Add a borrow request where a user can request an item and choose their borrowing time.
**Request Accept/Reject:** Add a accept and reject option so that if someone want to borrow one of the owner item, the owner can either accept or reject their offer.
### Sprint 3
**Notification System:** Add a notification system that alert a the user when someone request one of their items.

**Others:**
Identity Verification: Add identity verification

## Feature
A distinct piece of functionality in the application.

Describe the feature clearly and concisely: what does it let the user or system do?

Example:
Loan application form — lets a loan officer create a new loan application by entering the applicant's citizen number, name, date of birth, job details, references, and requested loan amount.

### Sprint 1
- **Browse Page** — lets a student look through a page with a bunch of items that are currently available for lending.
- **Listing Form** — lets a student be able to list an item in the browse page by creating a listing form
- **Search Bar** — lets a student search for a specific item in a search bar so they can find what they want quickly.
- **Account Management** — lets a student create an account by entering name and password, by this the student can now view their personal information.
### Sprint 2
- **Filter Option** — lets a student filter by some category so they can find what they want easier.
- **Account Page** — lets a student to have an account page so they can view their personal information and change it if needed.
- **Borrow** — lets a student borrow an item from a another student for a certain period of time.
- **Lend** — lets a student list one of their own items so other students can borrow it.
- **Request** — lets a student send a borrow request to an item owner, the owner can either accept or reject the item.
### Sprint 3
- Notifications — lets a student receive an alert when someone want to borrow one of their items.

## User Story
A piece of functionality described from the user's perspective.
As a [type of user], I want [to perform some action] so that [I can accomplish some goal].
Example:
As a loan officer, I want to search for a customer by their citizen number so that I can quickly find their existing loan applications.

### Sprint 1
**Browse page for items**
- As a student, I want to look through a bunch of items that are currently available for lending.
**Listing form for items**
- As a student, I want to be able to add one of my items  in a listing form so that other students can look at my item.
**Search for items**
- As a student, I want to search for a specific item so that I can find it quickly.
**Account creation**
- As a student, I want to be able to create an account so that save my data to a personalized account.
### Sprint 2
**Filter by Category**
- As a student, I want to filter items by category so that i can narrow down what I am looking for.
**Account page**
- As a student, I want to have an account page so that I can view my personal information and update data.
**Borrow item**
- As a student, I want to borrow an item from another student so that i can use it for a certain period of time.
**Lend item**
- As a student, I want to lend an item to another student so that i can share things that I'm currently not using.
**Request Item**
- As a student, I want to get notification when someone requests one of my items so that I can accept or reject their request.
### Sprint 3
**Notify on Request**
- As a student, I want to get a notification when someone request one of my items so that i can accept or reject their request
